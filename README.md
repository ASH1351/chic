# Chic Couture — “Wear Confidence”
### Premium Luxury Fashion E-Commerce Digital Flagship

Chic Couture is a digital fashion flagship inspired by the visual quality of luxury fashion houses (*Saint Laurent, Chanel, Khaite, Celine*) and high-end fashion editorial magazines (*Vogue, Harper's Bazaar*). 

The platform is designed around the core tagline: **“Wear Confidence.”**

## Key Features

1. **Editorial Hero Carousel**:
   * 3 runway slides with season tagging (*Capsule No. 04*), gold script accents, dual CTAs, and 4 luxury value pillars.
2. **Curated Capsules Spotlight**:
   * *Haute Gala & Red Carpet*, *Modern Power Tailoring*, *The 22-Momme Silk Archive*, and *Golden Riviera Resort*.
3. **Faceted Product Catalog**:
   * Dual view toggle: Standard 4-Column Grid vs. Large Editorial 2-Column Spread.
   * Real-time filtering by Category, Fabric, Tonal Color, Size, and Atelier Exclusives.
   * Sorting by Featured, Price (Low/High), Customer Rating, and Newest Arrivals.
4. **Interactive Runway Lookbook**:
   * Fullscreen high-fashion editorial layouts with pulsing champagne gold pins allowing direct garment inspection and instant bag addition.
5. **In-Depth Product Detail Modal (PDP)**:
   * Multi-angle gallery with zoom-on-hover.
   * Dynamic currency formatting with Indian Rupee (₹) default (`en-IN` numbering) and 4-installment EMI calculations.
   * Interactive **Size Guide & Fit Assistant** with Bust, Waist, and Hip body measurement calculator.
   * **Complete The Look** curated ensemble bundling.
6. **Slide-Over Shopping Bag**:
   * Live free-shipping progress meter.
   * Complimentary signature gift box with wax-sealed card toggle.
   * VIP Courtesy code validation (`CONFIDENCE15` for 15% off, `ATELIER20` for 20% off).
7. **Multi-Step Luxury Checkout**:
   * Contact and residence address capture.
   * White-glove delivery method selector (Complimentary Express vs. VIP Chauffeur).
   * Encrypted payment with interactive luxury credit card preview.
   * Order placement with champagne gold confetti celebration and printable official receipt.
8. **Private Atelier Booking**:
   * Flagship appointment concierge for Paris, New York, Milan, London, Dubai, or Virtual Haute Consultation.
9. **Global Currency Switcher**:
   * Instant toggle between **INR (₹)**, **USD ($)**, **EUR (€)**, **GBP (£)**, **AED**, and **JPY (¥)**.

## Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/ASH1351/chic.git
cd chic
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```
